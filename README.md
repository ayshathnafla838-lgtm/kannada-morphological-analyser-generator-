Kannada Morphological Analyzer and Generator Using Deep Learning

Project Overview

This project focuses on Kannada Natural Language Processing (NLP). It aims to analyze and process Kannada words using deep learning techniques.

Technologies Used

- Python
- PyTorch
- Tkinter

Features

- Graphical user interface for Kannada text input
- Virtual Kannada keyboard with letters, matras, and numbers
- Text comparison and correction workflow
- Part-of-speech (POS) information display

Project Structure

- "morphological_analyzer.py" — Main Python application
- "requirements.txt" — Python dependency list
- "docs/" — Project documentation
- "data/" — Dataset documentation

Current Status

The main Python application and initial documentation have been uploaded to GitHub. Supporting model architecture, trained model, and vocabulary files still need to be added and verified before the application can run completely.
